# PawnCore 모듈 문서

이 문서는 게임 내 "폰(Pawn)" (게임 엔티티/캐릭터)의 핵심 기능을 관리하는 `PawnCore` 모듈의 구조와 책임을 설명합니다. 이 모듈은 중앙 `PawnManager`와 다양한 `PawnSubManager` 구현을 사용하여 폰 동작의 특정 측면을 처리하는 모듈식 설계를 채택합니다.

## 1. 전반적인 목적

`PawnCore` 모듈은 게임 엔티티(폰)를 정의하고 관리하기 위한 유연하고 확장 가능한 프레임워크를 제공하도록 설계되었습니다. 이동, 전투 및 입력 처리와 같은 특정 기능을 전용 서브매니저에게 위임하여 관심사를 분리함으로써 유지 보수 및 기능 확장을 용이하게 합니다.

## 2. 주요 구성 요소

### 2.1. PawnManager

-   **파일:** `PawnManager.cs`
-   **역할:** 폰의 중앙 오케스트레이터입니다. 다음을 담당합니다:
    *   다양한 `PawnSubManager` 인스턴스의 생명주기 초기화 및 관리.
    *   다른 서브매니저 간의 상호 작용 조정.
    *   외부 시스템이 폰과 상호 작용할 수 있는 통합 인터페이스 제공.

### 2.2. PawnSubManager

-   **파일:** `PawnSubManager.cs`
-   **역할:** 모든 특정 서브매니저의 기본 클래스 또는 인터페이스 역할을 합니다. 모든 서브매니저가 구현하거나 준수해야 하는 공통 메서드 또는 속성을 정의하여 일관된 구조를 보장합니다.

### 2.3. 특정 서브매니저

`SubManagers` 디렉토리에 있는 이 클래스들은 폰의 특정 기능을 구현합니다:

-   **`DamageableSubManager.cs`**: 폰의 체력, 피해 입히기 및 관련 이벤트(예: 죽음)를 처리합니다.
-   **`MovableSubManager.cs`**: 속도, 방향 및 충돌 감지를 포함한 폰의 이동 로직을 관리합니다.
-   **`PlayerAttackInputSubManager.cs`**: 공격 동작에 대한 플레이어 입력을 특별히 처리합니다.
-   **`ProjectileCollisionSubManager.cs`**: 투사체의 충돌 감지 및 효과를 처리합니다.
-   **`ProjectileMovementSubManager.cs`**: 투사체의 이동 동작을 제어합니다.
-   **`ProjectileShooterSubManager.cs`**: 폰이 투사체를 발사하는 로직을 구현합니다.

### 2.4. IAttackable

-   **파일:** `IAttackable.cs`
-   **역할:** 공격받을 수 있는 모든 엔티티에 대한 계약을 정의하는 인터페이스입니다. 이 인터페이스를 구현하는 엔티티는 피해를 받거나 공격 이벤트를 처리하는 메서드를 제공해야 합니다.

### 2.5. Usecases

`Usecases` 디렉토리에 있는 이 클래스들은 특정 도메인과 관련된 고수준 작업 또는 유틸리티 함수를 제공합니다:

-   **`CombatUsecases.cs`**: 전투 시나리오(예: 피해 계산, 상태 효과 적용)와 관련된 로직 및 유틸리티를 포함합니다.
-   **`MovementUsecases.cs`**: 이동(예: 경로 찾기, 이동 제약)과 관련된 로직 및 유틸리티를 포함합니다.

## 3. 구성 요소 상호 작용

`PawnManager`는 중앙 허브 역할을 합니다. 초기화 시 다양한 `PawnSubManager` 인스턴스를 인스턴스화하고 등록합니다. 폰의 생명주기 동안 `PawnManager`는 등록된 서브매니저의 메서드를 호출하여 특정 작업(예: `PawnManager.Update()`가 `MovableSubManager.UpdateMovement()`를 호출할 수 있음)을 수행할 수 있습니다. 서브매니저는 `PawnManager`를 통해 또는 책임이 밀접하게 연결된 경우 직접 상호 작용할 수도 있습니다.

## 4. 확장 방법

폰에 대한 새로운 기능을 추가하거나 기존 기능을 수정하려면:

1.  **새로운 기능:** 특정 기능(예: `BuffDebuffSubManager`)에 대한 새로운 `PawnSubManager` 구현을 생성합니다. 이 새로운 서브매니저를 `PawnManager`에 등록합니다.
2.  **기존 기능 수정:** 관련 `PawnSubManager`를 찾아 로직을 수정합니다.
3.  **새로운 유스케이스:** 고수준의 재사용 가능한 로직의 경우 `Usecases` 디렉토리에 새로운 유스케이스 클래스를 생성합니다.
